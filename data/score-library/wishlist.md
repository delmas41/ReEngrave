# IMSLP download list — 103 orchestral scores

Generated by `python3 -m tools.library.build_wishlist`, which reads every file in
each work's *Full Scores* section and ranks them for OMR use: a real engraving beats
a modern typeset, a named publisher beats an anonymous upload, and an edition series
we already hold beats one we don't — same engraver, same conventions, so a difference
between two scores is the music rather than the print.

Each link is a permalink that resolves to the file. **IMSLP gates downloads behind a
JavaScript redirect**, so open these in a browser where you are logged in; `curl` gets
the gate, not the score.

After downloading, everything in `~/Downloads` goes in with one command:

```bash
python3 -m tools.library.ingest imslp ~/Downloads/IMSLP*.pdf
```

## A caution on page counts

The page count is what IMSLP lists, and it identifies the edition as much as the publisher does: Beethoven's third runs 89pp in the Litolff and 176pp in the Eulenburg, and neither is wrong. A count far outside the band for a work usually means a complete-works volume or a single movement, not a full score.
