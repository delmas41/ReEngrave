Orchestral scores worth pulling from IMSLP

Every work below was checked against IMSLP's own file listing, and the edition named is the one ranked best for optical music recognition — which is not the same as best to play from. A real 19th-century engraving beats a modern typeset, because the engraving is the problem this pipeline exists to read. A named publisher beats an anonymous upload. And an edition series already in the library beats one that isn't: same engraver, same conventions, so a difference between two scores is the music rather than the print.

IMSLP gates file downloads behind a JavaScript redirect, so open these links in a browser where you're signed in — curl gets the gate, not the score. Afterwards the whole folder goes in with one command:

python3 -m tools.library.ingest imslp ~/Downloads/IMSLP*.pdf

Three that got away

Beethoven's Leonore Overture No. 3, Ravel's Ma mère l'Oye, and Lili Boulanger's D'un matin de printemps are filed under titles that neither the guessed name nor the search fallback matched. They exist — find them by hand and add them the same way.

On reading the page counts

Page count identifies an edition as much as the publisher does. Beethoven's third runs 89 pages in the Litolff and 176 in the Eulenburg, and neither is wrong. A count far outside the band for a work usually means a complete-works volume or a single movement rather than a full score — worth a look before downloading.
