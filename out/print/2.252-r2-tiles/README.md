# 2.252 round 2 tiles

Each picture is a piece of a scanned score page, one staff, with ONE thin orange box and nothing else drawn. The box only says where to look; it says nothing about what we read. Each picture is wide enough to show the notes before and after the box and the whole of every arc between them.

**Question, for every tile:** how many notes are in the orange box, and is each of them tied (the same note held) to the note before it, the note after it, both, or neither?

Answer by tile number.
