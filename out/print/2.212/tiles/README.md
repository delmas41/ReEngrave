# Tiles

Each picture is a piece of a scanned score page with ONE orange box on it and nothing else drawn. The orange box only says where to look: it is on one note head.

**Question, for every tile:** what is the pitch of the note head at the orange box -- the staff line or space it sits on, and the note name for the clef and key you can see? If the clef is not in the picture, say which clef the staff is (or "can't tell").  Answer by tile number.
