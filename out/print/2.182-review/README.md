# 2.182 review -- how many parts are in the bar in the blue box?

8 tiles, each a crop of the printed score (Beethoven 5 Litolff, or Brahms 1 Breitkopf) with ONE blue box drawn around ONE BAR on ONE staff, and nothing else of ours. The blue box is only the place to look; it is not a reading.

For each tile: **how many parts are in this bar, and what are the notes' values in each part (upper / lower)?** For example `2 parts: upper 8 8 8 rest8 / lower dotted half`, or `1 part: q q q`. Answers go in `answers.json` beside this file.
