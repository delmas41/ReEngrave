# 2.221 census tiles (read-only; nothing about any change)

Each picture is a piece of a scanned score page with ONE orange box on it and nothing else drawn.

**What the orange box means.** It is a place where our reader WROTE a note into the file (or, on a few tiles, a note together with an accidental, rest or dot that the detector boxed next to it; the box then holds both). It says nothing about whether we were right.

**Question, for every tile:** what is inside the orange box? Is it a real note head, or is it part of something else (a letter of a dynamic or word, a barline, a bracket, part of a sharp or rest)? If a note and something else share the ink, which one owns the shared ink?

Answer by tile number. Our key is in `../key.json`, outside this folder, and is not for the reader.
