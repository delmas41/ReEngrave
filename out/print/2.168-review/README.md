# 2.168 blind tiles (10)

Each tile shows one note with ONE blue box on it. Blue = the note asked about. Nothing else of ours is drawn.

Question for every tile: what is the written value of the note in the blue box (4, dotted 4, 8, 2 ...)?

Answer into `answers.json` (tile number -> value). The key (which tiles are notes the bar disputes and which are plain
controls) is `out/2.168/tiles-key.json` and is not to be read before answering.
