# Capture tiles

Each picture is a piece of a scanned score page with ONE orange box on it and nothing else drawn. The box only says where to look.

**Question, for every tile:** what is this ink (a note, a stem, a beam, a rest, a flag, an accidental, a dot, a tie or slur, a hairpin, a word or dynamic, a bracket, a barline, or something else)?

Answer by tile number.

Where the box is around a CLEF, the question is also: does the box hold ALL of that clef's ink (its tail, its top curl, its dots)?
