# Lane report tiles

Each picture is a piece of a scanned score page with ONE orange box on it and nothing else drawn. The orange box only says where to look; it means nothing about what we read.

**Question, for every tile:** what does the print show at the orange box (a note and its value, a rest and its value, an accidental, a dot, a flag or beam, a tie or slur, a mark, or nothing there)? Is anything about it that we might have written wrongly?

Answer by tile number.
