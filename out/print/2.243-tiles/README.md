# 2.243 tiles (12)

Each picture is a piece of a scanned score with ONE thin orange box and nothing else drawn. The box only says where to look.

Question, for every tile: what is the ink in the orange box?
- a small dot beside or above a note (a dot that lengthens it, or a staccato dot), or
- not a dot (the end of a slur or hairpin, part of a word, something else), or
- a note head / beam / flag: say how many beams or flags it carries, and whether it is an eighth, a sixteenth, a quarter.

Answer by tile number. The key is outside this folder.
