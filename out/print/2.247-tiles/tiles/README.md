# 2.247 accidentals by their shape: 12 blind tiles

Each picture is a piece of a scanned score page with ONE thin orange box and nothing else drawn. The box only says where to look.

**Question, for every tile:** Is the mark in the orange box a sharp, a flat or a natural? (Or part of one -- say which -- or not an accidental at all.)

Answer by tile number (e.g. `1 natural, 2 flat, 3 part of a natural ...`).
