# interior-{brahms,litolff}-{black,hollow}-closest.png
Four heads per strip, 600 dpi raw page, black = ink. Black strips: the four LOWEST-reading black heads under variant (c); hollow strips: the four HIGHEST-reading hollow heads under (c).
* GREEN rectangle: the standard head box (1.4 x 1.1 staff spaces) the re-centre search placed.
* MAGENTA rectangle: that box's centre window (what the interior fraction is read in).
* Caption: a = current window on the given box, b = re-centred window, c = re-centred with the staff-line rows left out (fraction of ink, 1.0 = solid).
* Litolff "black" = production black-class boxes that Sean's hollow-only truth does not call hollow, so some are unlabelled hollow heads or not heads.
