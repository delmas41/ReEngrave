# 2.252 tiles

Each picture is a piece of a scanned score page, one staff, with ONE thin orange box and nothing else drawn. The box only says where to look; it says nothing about what we read. Each picture shows the whole of every arc that touches the boxed notes, and the notes at the arcs' other ends.

**Question, for every tile:** how many notes are in the orange box, and is each of them tied (the same note held) to the note before or after it?

Answer by tile number.
