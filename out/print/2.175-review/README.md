# 2.175 review tiles (blind)

12 tiles, STAGED, records 20261018-night. Page crops, nothing of ours drawn except ONE blue box on the head.

**The question on every tile: how many notes does the blue-boxed head stand for, and what is each one's value?** (for example "two: 8 and 4", "two: 8 and 8", or "one: 4").

Tiles and `key.json` (ours: what the OFF/ON arms read, plate, subject, which are the 2 controls) were written by one run of `benchmarks/omr-unison-two-voices-2026-10/probe/tiles_2_175.py` and checked equal (same ids, same order, distinct subjects): 12 tiles = 12 key rows.
