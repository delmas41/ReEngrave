# 2.165 blind tiles (12)

Each tile shows one note with ONE blue box on it. Blue = the note asked about. Nothing else of ours is drawn.

Question for every tile: what is the written value of the note in the blue box (4, dotted 4, 8, 16, 2 ...)?

Answer into `answers.json` (tile number -> value). The key (which tiles are notes the one-note correction changed and which are
2 plain controls) is `out/2.165/tiles-key.json` and is not to be read before answering.
