# 2.248 round 3 -- 12 tiles

Each picture is a piece of a scanned score page with ONE orange box on it and nothing else drawn.

**One question, for every tile:** is the notehead in the orange box sitting ON a line (or a ledger line) or IN a space?

Answer by tile number: `line` or `space` (and `not a note` if it is not a head).
