# Lane report tiles (wide)

Each picture is a piece of a scanned score page, one staff, with ONE orange box on it and nothing else drawn. The orange box only says where to look; it means nothing about what we read. Each picture shows the whole arc near the box, the notes it joins, and about one note either side.

**Question, for every tile:** at the orange box, is the arc a tie (the same note held) or a slur, and does it join the note in the box?

Answer by tile number.
