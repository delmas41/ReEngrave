# 2.180 blind tiles -- augmentation dots (12 tiles, Brahms 317803)

Each tile is the print around one note. The BLUE box is drawn on the note we ask about; nothing else of ours is drawn.

Question for every tile: **what is the written value of the note in the blue box (e.g. dotted 4, 4, dotted 8)?**

Some tiles are controls. The key (what we wrote, flag off and on) is in `_key/key.json`, outside `tiles/`; tiles and key
come from one run of `benchmarks/omr-augmentation-dots-2026-10/probe/tiles_2_180.py`, checked equal.
