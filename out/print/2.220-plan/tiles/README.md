# 2.220 plan tiles (ink map step 6, fill)

Eight pieces of score pages (Litolff and Brahms, Beethoven 5 / Brahms 1). Each has ONE orange box and nothing else
drawn. The orange box only shows where to look. It says nothing about what we read.

**Question for every tile:** what is in the orange box? A hollow head (half note), a filled head, or not a note
(say what it is)?

Answer per tile number, e.g. `1 half, 2 not a note (ff)`. The key is outside this folder (`../key.json`).
