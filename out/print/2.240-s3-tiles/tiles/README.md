# Two plain questions

Each picture is a piece of a score page with ONE orange box on it and nothing else drawn. The box only says where to look.

**For every tile:** what is the ink in the box (a note, an arc, a hairpin ...), and is it ONE mark or more?

**If it is a note:** does it belong to the full five-line staff in the picture, or to another staff (the one above or below, partly shown or not shown)?

Answer by tile number.
