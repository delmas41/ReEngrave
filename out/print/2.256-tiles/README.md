# 2.256 tiles

Each picture is one staff of the Litolff Beethoven 5 score, from its left edge. ONE orange box marks where the key signature stands. Nothing else is drawn.

**Question, for every tile:** how many flats (or sharps) does the printed key signature show at the orange box on this staff, and are they all clear? Answer by tile number, e.g. `1: 3 flats`, `2: 1 flat`, `3: none`.
