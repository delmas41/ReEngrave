# 2.254 hairpin tiles

Each picture is one staff of a scanned Brahms page with ONE thin orange box and nothing else drawn. The box only says where to look.

**Question, for every tile:** is the mark in the box a hairpin (crescendo or diminuendo), an accent, or something else? If a hairpin: which staff does it belong to, and on which notes does it start and stop?

Answer by tile number.
