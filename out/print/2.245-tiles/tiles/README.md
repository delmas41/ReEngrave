# 2.245 tiles -- what is the ink in each box?

Twelve tiles, one staff each, from the Litolff Beethoven 5 and the Breitkopf Brahms 1 scans. Each has ONE thin orange box; the orange only shows where to look, it is not a reading.

**For each tile: what is the ink in the box, and is it one mark?** (for example: a note, two notes, part of a slur, part of a hairpin, a ledger line, a rest, a beam.)

The answers go in `../answers.json`.
