## Position tags for noteheads

DeepScoresV2 distinguishes `noteheadBlackOnLine` from `noteheadBlackInSpace`, but SMuFL has a single `noteheadBlack` glyph. We render the same glyph in both cases and overlay a small horizontal staff-line indicator behind the glyph: one line through the middle for **OnLine** variants, two flanking lines for **InSpace** variants. Look at the tile, not just the filename.
